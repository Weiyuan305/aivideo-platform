# 剪辑一致性与十分钟性能验收（2026-10-15）

范围：上传素材 → 实时多轨预览 → 保存版本 → CPU worker 导出 → MP4 播放、下载。真实模型 API 保持关闭。这里区分实际浏览器操作、自动编码检查和目标设备尚未验证的部分。

## 本轮发现与修复

| 问题及证据 | 修复 |
| --- | --- |
| 导出自动限幅器默认补偿增益；单声道在 FFmpeg 转立体声时电平也与浏览器不同 | 预览和导出共用 `timelineMixGain`，按时间重叠计算固定混音余量；单声道显式复制到左右声道，移除独立自动增益 |
| DOM 视频图层与未标记的 YUV 合成在淡化中段存在色差 | 原生媒体解码后用 sRGB Canvas 合成；导出显式转换、标记 SDR 色彩空间，图片先处理方向、色彩配置与透明黑底 |
| 长时间播放中，时钟将单帧 elapsed 截断为 100 ms，繁忙帧累计导致播放落后 | 保留真实 elapsed；缓冲和隐藏标签仍暂停。恢复时同步媒体与统一帧时钟 |
| 字幕到起点才请求和解码，连续播放出现停顿 | 提前加载当前与后两条字幕，最多缓存 12 张；跳转时保护当前使用的缓存 |
| 100 镜头、20 配音、200 字幕产生 32,885 个 DOM 节点，编辑器重 | 配音和字幕各按 5 条分页，新增条目自动定位所在页；完整时间轨与保存数据保留。节点降至约 3,630 |
| 长片只靠滑块难以精确定位 | 增加秒数输入，按 30 fps 定位，可配合上一帧/下一帧 |

主要源码：`apps/web/features/timeline/timeline-preview.tsx`、`timeline-editor.tsx`、`apps/web/app/globals.css`、`packages/core/src/timeline.ts`、`packages/server/src/render.ts`、`render-color.ts`。复用 FFmpeg、Sharp/Pango、wavesurfer.js、现有队列和归档；没有增加 GPU、Redis、浏览器渲染服务或模型部署。

## 固定验收素材

本机项目：**剪辑一致性与十分钟压力验收**，分集：**十分钟 · 100 镜头 · 20 配音**。

- 项目 ID：`1d64f819-ac3d-4913-bcd6-ff27fcdf8b9d`；分集 ID：`4bcbde5f-8b61-43fd-b5ab-d959fc49294e`。
- 横屏 1280×720、30 fps、600 秒。100 段交替的运动测试视频和竖幅图片，66 次交叉淡化、33 次向右擦除，每次 0.5 秒。
- 20 段配音，来自四个不同频率的合成音文件；每隔 30 秒进入，最长 120 秒。最大同时播放 **4 段配音和视频原声**，不是 20 轨同时发声。
- 200 条双行中文字幕，每 3 秒一条、持续 2 秒，包含顶部/居中/底部、对齐、字号、粗体、白字和黄字。
- 六个唯一上传文件，约 46 MiB。全部为自建测试图、运动色卡和合成音；不涉及个人声音或真实模型输出。

素材复杂度覆盖当前数量、时长上限；不代表 1 GB 输入、4K 解码、高码率实拍或全部 20 轨同时发声的性能上限。

## 一致性证据

- 最终 v1 成片任务 `b7ce0429-508a-4eb6-8aca-f375333e1396`，输出素材 `6de5b9c7-3b94-4524-a288-04876ae0da2a`。实际下载并 ffprobe 确认 H.264/AAC、1280×720、600.000 秒、18,000 视频帧；BT.709 矩阵和原色、sRGB transfer、limited range 标记存在。
- 在浏览器精确定位并读取实际 Canvas 帧，对照最终 MP4 解码帧 15、172、532、17,940：覆盖中文字幕、淡化中点、擦除中点、竖图黑边和片尾字幕。平均 RGB 通道绝对误差分别为 **3.87、4.06、2.63、0.43 / 255**。文字内容、换行、位置、转场方向和重叠时点一致；输出是有损 8-bit YUV，不能声称逐像素相同。
- 在 1、10、100、200、300、450、580、598 秒分别解码 0.5 秒音频，按原始 PCM、裁剪位置和共用增益计算参考。导出 RMS / 参考 RMS 为 **0.99809–0.99963**，电平偏差低于 0.2%；AAC 波形归一化误差约 0.5%–1.6%。这是数字信号检查，不是主观音质评分或扬声器回录。
- 自动编码测试覆盖单声道、叠加配音、视频原声交叉淡化、透明图片黑底，及字幕开始前/开始帧/最后帧/结束帧。字幕 PNG 与最终烧录共用同一排版实现。

## 性能与浏览器验收

环境：本机 macOS、Apple M5、32 GiB RAM，FFmpeg 8.1，生产构建，localhost 私有素材存储。测试中并行运行了浏览器、部分构建/回归；这里是开发机观测，不是云服务器 SLA。

| 指标 | 实测 |
| --- | --- |
| v1 提交到归档成功 | 221.575 秒，约 3 分 42 秒 |
| 实际文件大小 | 70.65 MiB |
| worker 与 FFmpeg 子进程 RSS 峰值 | v1 完整采样 1,377.12 MiB；v2 后半段另观测到 1,634.88 MiB；完成后约 156–187 MiB |
| 临时合成文件峰值 | 两次观测最高 504.65 MiB；完成后归零 |
| 进程合计 CPU 峰值 | 370.3%，约 3.7 个逻辑核心；不是整机占用 370% |
| 桌面连续预览 | 600 秒完整播放到末尾并自动暂停；600.01 秒观测到完成 |
| 桌面浏览器主线程 | 600 秒窗口 TaskDuration 约 19.5%，JS 执行约 6.0%；末尾 JS heap 30.8 MiB |
| 移动视口预览 | 390 像素下完整播放 600 秒；320 像素下编辑定位、逐帧、播放、下载通过 |

RSS 为约每秒采样的进程总和，不含 Web/PostgreSQL、浏览器 GPU/解码内存，也不保证捕捉亚秒峰值。JS heap 不是整个浏览器内存。既有单任务 CPU worker 足以完成该样例；同机部署宜预留至少 4 GiB 内存与足够私有存储，2 GiB 机器及真实云 CPU 尚未验证。

桌面使用 1422 CSS 像素宽；移动端检查 390 / 320 CSS 像素，页面 `scrollWidth` 分别等于 390 / 320，无页面横向溢出，时间轨保留局部滚动。移动视口是在本机 Chromium 中缩放布局，不能替代 iPhone Safari 或 Android 真机。

390 像素视口连续预览从头到尾，567.43 秒时观测到播放位置 567.57 秒，608.10 秒检查时已到 600 秒并自动暂停；未测量精确结束事件时间。该窗口主线程 TaskDuration 约 18.4%，JS 执行约 5.9%，末尾 JS heap 43.2 MiB。中段四条配音媒体时钟换算至全片后彼此相差约 16 ms，音量均等于共享混音公式。未见相关浏览器错误日志。

移动操作覆盖：跳到字幕第 40 页、修改第 200 条文字、切到配音第 4 页并载入波形、保存 v2、提交后台导出；320 像素下刷新仍显示已保存 v2 和修改后的文字，使用“预览此字幕”、秒数输入及前后逐帧。实际 MP4 成功播放，浏览器下载的文件 SHA-256 与服务端归档文件相同（`eaf8d873953512c34d07d33afb720ce7b7fed38be41598605f4cffdf65367cab`）。v2 第 17,940 帧实际预览与导出的平均 RGB 通道绝对误差为 0.45 / 255，中文内容与排版一致。临时视口覆盖在测试后已恢复。

移动端 v2 任务 `57b8ac5e-a546-4885-b685-c73ec8dd7c4e`，输出 `5a927836-1e77-453a-ace1-e3b0e83f9ebf`；提交至归档 **189.621 秒**，实际文件仍是 600 秒、18,000 帧、70.65 MiB。v2 的资源监测从中途开始，因此它只提供已观测峰值，不能当作完整第二次资源曲线。

额外排查了 20 段音频的延迟缓冲：保持相同音频和时间参数，单独用 `adelay` 和按需静音拼接对照，系统 maximum RSS 分别约 45.8 MiB / 43.8 MiB；不足以说明它是整片内存峰值的主要原因，因此没有据此改写已经验证的音频时点逻辑。

## 未覆盖与明确限制

- 真机 iOS/Safari 的媒体播放和音量策略、Android、低端设备、慢网/远程 S3 以及目标部署机器尚未验收。
- 当前以 SDR 8-bit 合成为目标；PQ/HLG HDR 输入明确拒绝导出，提示先转换为 SDR。HDR 色调映射、专业色彩管理、宽色域精确一致性未实现。
- 声音遵循共用线性混合规则；尚无响度标准化、压缩器、降噪、自动闪避、专业监听或 lip-sync 验收。
- 实时预览仍是浏览器帧时钟与媒体同步，资源紧张时允许丢画面帧追上时钟，不承诺每种设备都恒定输出 30 fps。
- 4K 输出、多层自由视频叠加、关键帧、复杂转场、自定义字体和自动字幕仍不在当前实现范围；真实模型 API 保持未接入。

色彩实现参考：[FFmpeg filters 官方文档](https://www.ffmpeg.org/ffmpeg-filters.html)、[Canvas getContext 官方说明](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext)。测量结论来自上述实际产物与本机浏览器，不以文档替代运行证据。
