# 分集剪辑与成片导出

本轮范围：已采用镜头和上传图片/视频进入分集时间线；排序、裁剪入点、时长、原声、配音、字幕；保存版本、后台生成真实 MP4 预览、下载和素材复用。所有模型继续关闭。

## 完成条件
- 已采用镜头按分镜顺序追加，可拖动、键盘或按钮排序；保留采用版快照，不随候选变化。
- 图片/视频和音频使用现有私有素材上传；秒数转为 30 fps 整数帧，校验边界。
- 镜头绑定的字幕/配音随排序移动；全片轨支持绝对时间；字幕烧录进 MP4，并可下载 SRT。
- 保存使用项目 revision 防覆盖；合成冻结已保存版本，任务重试、取消、归档、历史和删除引用保护复用现有底座。
- CPU worker 用 FFmpeg 合成 H.264/AAC 720p；Sharp/Pango 排版字幕并输出 PNG，避免依赖 FFmpeg libass；dnd-kit 处理排序。无 GPU、Redis、Chromium 或模型服务。
- 预览播放实际归档 MP4，下载同一文件；编辑后旧预览明确标注版本。
- 单集最多 100 段、10 分钟、20 配音、200 字幕，串行分段编码、限线程/进程时间/输入总量/输出大小，私有临时文件清理。

## 实施步骤
1. contracts/timeline.ts + core/timeline.ts：时间线、导入、时间换算、SRT、验证；扩展 production/task 引用与快照。
2. server/render.ts：受限媒体探测和 FFmpeg 管线、Sharp 字幕、私有归档；service/production/listing 和 API 对接。
3. features/timeline：编辑、保存、上传/素材选择、预览任务与版本、下载；任务中心和历史识别合成任务。
4. 单元：时间/排序/字幕锚点/版本/错误输入；服务端：真实视频+配音+字幕导出、时长/画面/音频、所有权/幂等/取消/归档/重试/引用保护。
5. lint/build/source-check/full regression；浏览器桌面/移动操作链路，保留可复查成片与截图。

## 首期边界
硬切剪辑和单字幕轨，不含转场、调色、关键帧、实时代理预览、自动转录、多人协同或高级音频波形。部署需 FFmpeg/ffprobe 与中文字体；使用服务器已有 CPU worker。

## 完成记录

上述 5 步已完成。2026-10-15 最终生产构建通过；53/53 单元、46/46 服务端和真实 HTTP 测试全部通过，无跳过；lint、format 和 62 项来源哈希通过。浏览器实际操作覆盖采用版导入、键盘/按钮排序、音频与镜头上传、字幕和 SRT、横屏/竖屏 MP4 下载与播放、成片再剪辑、任务/历史/素材跳转，以及 390/320 CSS 像素布局。

验收发现并修复：JSONB 键序导致提交快照比较失败；输出对象键不符合现有私有存储规则；字幕排版被自动放大；字幕图片流默认 25 fps 导致帧边界量化；取消时子进程尚未退出就清理临时文件。各项修复分别由提交/归档、实际字幕图像与媒体采样、取消/清理回归覆盖。实际播放器与下载均使用最终归档 MP4。

细节、部署与未覆盖边界见 `docs/timeline-export.md`。保留实际测试成片 `.runtime/timeline-acceptance/render-verified.mp4` 和页面截图；普通本机工作区的“验收 · 末班地铁”项目含 3 次成片输出，最终剪辑 v4 使用采用镜头、成片复用和新上传图片。未调用真实模型 API。
