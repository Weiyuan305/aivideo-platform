# 无密钥任务、历史与工作流执行增量

本轮范围：继续原首期方案的任务状态、历史、DAG 执行基础；保持单浏览器本地工作区，不接付费 API、云存储、数据库或云任务。

## 可观察验收标准

- [x] Studio 提交保存不可变的参数、引用和任务事件；无密钥明确进入待接入状态，页面刷新仍可查看。
- [x] 任务中心支持状态/类型/关键词筛选、详情、取消和明确可安全重试的任务；提交结果不确定时禁止自动重试。
- [x] 生成历史展示真实提交记录；可复用参数、查看引用素材、导出记录；无输出时不展示伪造媒体。
- [x] 工作流使用冻结图快照执行六类节点，解析连线输入并保存逐节点检查点；试运行使用明确标注的计划引用，不制造文件。
- [x] 支持试运行中断恢复、取消、失败重试、历史回看；运行快照的引用受到删除保护。
- [x] 新存储升级保留已有素材、声音、工作流；同源多标签页通过 Web Locks 互斥和本地通知协调。
- [x] 单元测试覆盖状态机、依赖传值、失败与恢复；浏览器验证取消冲突、多标签调度、Studio → 任务 → 历史与工作流运行链路、刷新和移动端。

## 实现顺序

1. contracts：任务、事件、节点检查点、参数协议；core：IndexedDB 升级与原子更新。
2. core：纯 DAG 执行与状态转换；浏览器调度器和服务端 API 预留接口。
3. Studio 提交记录；任务中心、详情、历史、参数复用。
4. 工作流试运行/提交、节点状态和运行记录。
5. 回归验证、文档更新、本地生产预览。

## 边界

真实 API 继续明确返回未启用。试运行只验证依赖、资源与请求参数，节点输出为计划引用，不能冒充生成资产。浏览器打开时调度，刷新/关闭导致的中断保留检查点；关闭浏览器后的持续执行、服务端所有权、账单、结果归档仍由原计划的 PostgreSQL / Trigger.dev / S3 阶段完成。当前重试不会发起任何付费调用。
