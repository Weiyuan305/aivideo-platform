# 短剧项目与镜头选片

入口：`/projects`。仅使用已有的服务端工作区，真实模型适配器保持关闭。上传图片、视频和参考录音即可完成制作资料整理与选片。

## 使用流程

1. 创建项目，在“分集与分镜”中建立分集并粘贴剧本。也可先进入“角色与场景设定库”。
2. 为角色和场景上传或选择参考图片；每个设定最多 10 张。角色可绑定声音库中的参考声音，保存时同时固定录音素材 ID。这里保存设定资料，不训练或克隆模型。
3. 创建分镜，填写画面、台词、景别、运镜和计划时长，选择角色及场景的具体版本。通过“上移/下移”调整集内顺序。
4. 上传或复用素材库中的图片/视频，加入镜头候选。点击“采用此版”明确选片；新增候选不会自动替换采用版。采用视频的计划时长与文件实际时长是两个概念，目前不会自动裁剪。
5. 更新设定时会生成新版本；旧分镜继续引用旧版本。修改分镜会保留全部候选和采用版，并提示复核旧候选。展开“创建时的分镜”可看当时的描述、台词、角色/场景版本。设定历史可查看各版本参考图和固定录音。
6. 展开“工作流与任务”：采用图片可建立图生视频工作流；也可选择已有工作流。点击“试运行并关联”，由已有后台 worker 执行，关闭页面后仍继续。任务详情显示节点检查与冻结参数，试运行不会生成媒体。
7. 可粘贴已有任务 ID 进行关联。任务有归档图片/视频时，点击“导入结果”加入候选，再明确采用；服务端验证结果确实属于该任务。当前普通工作区没有真实模型输出，这一导入分支由隔离测试适配器验证。
8. 可解除任务或工作流关联，原记录会保留。候选保留来源任务链接，因此从任务列表解除关联后，来源任务仍可能受候选引用保护。

素材选择器同时展示文件名、上传时间和短标识，用于区分重复上传的同名文件。角色/场景参考、候选选片与剪辑素材使用同一套选择器。

删除项目仅删除制作资料及引用关系，不删除素材文件、声音、任务、工作流。被分镜或候选引用的设定不能删除；采用中的候选须先取消采用或切换其他候选。素材、声音、工作流或任务被任一项目引用时，原页面的删除接口会返回 409。

## 复用与新增代码

| 部分 | 实现 |
| --- | --- |
| 素材上传、校验、私有下载、音视频预览 | 复用 `core/local`、`workspace-client`、`ServerWorkspace.upload`、`DiskStorage/S3Storage` 与 `AssetPreview` |
| 声音资料 | 复用已有声音库；新增角色版本中的声音与录音素材引用 |
| 图生视频工作流 | 复用 `workflowFromImage`、`saveWorkflowVersion` 和 React Flow 编辑器；沿用现有模型 schema，不宣称已支持多参考推理 |
| 后台任务 | 复用 `submitWorkflowTask`、事务 outbox、pg-boss、现有 CPU worker 与任务详情 |
| 项目领域 | 新增 `contracts/production.ts`、`core/production.ts`、`server/production.ts`、`/api/production` 与 `features/production` |
| 数据保存 | 新增 `productions`（带 revision 的聚合 JSONB）和 `production_references`（引用索引）；素材不复制到项目表 |
| 权限和备份 | 复用 Better Auth、Origin 校验和原备份恢复流程；public schema 的备份自动包含新表 |

服务端锁定项目记录，并检查前端携带的 revision；过期修改返回 409，不覆盖新内容。界面会保留编辑内容并提示刷新后重新编辑。资源引用在同一事务中校验账号、锁定资源、更新引用索引，避免删除与引用并发产生悬空素材。

当前按单项目编辑设计，不是实时多人协作。项目上限：50 集、每集 100 镜、总计 500 镜、100 个设定、每设定 100 版、每镜 100 候选、每集剧本 50,000 字符，聚合 JSON 总长度不超过 2,000,000 字符。项目列表每页 20 项，按名称搜索。工作流保存/任务提交与项目关联为两步：若第二步冲突，已保存资源仍保留，刷新项目后可从已有工作流下拉框或任务 ID 重新关联。

## 2026-10-15 验收记录

最终结果：50/50 单元测试、41/41 服务端测试通过；构建、类型/边界、格式、62 项源码来源校验通过。

- 单元测试：固定设定版本、候选快照、排序完整性、采用版保护、引用收集与解除关联。
- PostgreSQL + DiskStorage 集成：真实上传图片/视频/录音，两分集两角色一场景，切换采用版，重新读取保持选择，既有工作流试运行，以及测试适配器产物归档导入。
- 权限/并发：跨账号项目与素材拒绝，错误素材类型/伪造任务输出拒绝，过期 revision 与双窗口并发只允许一次修改，引用创建和素材删除并发不产生悬空记录。
- HTTP：真实会话和 Origin 校验，上传到采用版完整链路，长中文剧本保存，重复读取、409 冲突与删除保护。
- 备份：实际 pg_dump/restore 恢复项目内容和资源引用保护，复用原数据库和素材恢复验证。
- 浏览器：桌面创建项目、两分集、角色/场景，上传多角度图片、视频、合成测试音；采用 A→B→新增 C→刷新仍保留 B；角色 v2 不改旧分镜 v1；后台试运行完成并打开任务详情；390/320 CSS 像素编辑、选片、关联/解除/重新关联及无横向溢出。窄屏历史录音默认 300px 宽度导致的溢出已修复。
- 本机保留“验收 · 末班地铁”示例项目。图片为纯色测试图、视频为测试色卡、音频为本机生成的测试音，仅用于操作验收。

自动化与浏览器测试均未调用真实模型。上述为项目与选片阶段验收；后续已增加剪辑时间线、配音、字幕和成片合成导出，见 [剪辑与成片说明](timeline-export.md)。真实供应商效果、远程生产环境、多人实时协作、自动拆镜和口型对齐尚未覆盖。
